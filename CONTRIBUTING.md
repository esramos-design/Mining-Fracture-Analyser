# Contributing to Mining Fracture Analyser

Thank you for considering a contribution to Mining Fracture Analyser (MFA).

MFA is a community-maintained open-source project. Contributions that improve accuracy, reliability, usability, documentation, testing, or maintainability are welcome.

## Ways to contribute

You can help by:

- reporting reproducible bugs;
- correcting outdated mining or equipment data;
- improving OCR reliability;
- contributing test cases;
- improving accessibility or usability;
- proposing or implementing features;
- improving documentation.

## Before opening an issue

Please check existing issues first where possible.

For a bug report, include:

- the MFA version or build used;
- browser or operating system where relevant;
- steps to reproduce the problem;
- expected behaviour;
- actual behaviour;
- screenshots or sample data when useful.

Do not include API keys, passwords, authentication tokens, private account information, or other secrets.

Security vulnerabilities should not be reported through a public issue. See [SECURITY.md](SECURITY.md).

## Pull requests

Keep pull requests focused on one logical change where practical.

A useful pull request should:

1. explain the problem being solved;
2. describe the proposed change;
3. identify any user-visible behaviour that changes;
4. include testing notes;
5. update relevant documentation when behaviour changes.

Avoid unrelated formatting changes in the same pull request.

## Data changes

When changing mining, ship, laser-head, module, gadget, or equipment data, include the source used to validate the change whenever possible.

Because Star Citizen is actively developed, data may change between game versions. Please identify the relevant game version when submitting game-data corrections.

## OCR contributions

OCR changes should include reproducible examples where possible.

Do not submit screenshots containing personal information, account identifiers, API keys, private chat content, or other sensitive information.

## AI-generated contributions

AI-assisted coding tools may be used, but contributors remain responsible for the submitted work.

Please review generated code before submission and verify that:

- it behaves as intended;
- it does not introduce secrets or private data;
- it does not copy code under an incompatible licence;
- tests or manual validation have been performed where appropriate.

## Code of conduct

Be constructive, technical, and respectful in project discussions. Focus criticism on the work rather than the person.

Thank you for helping improve MFA.
