# MFA Telemetry Probe

**Status:** research prototype for MFA vNext.

The probe passively follows the normal Star Citizen `Game.log` generated by the LIVE client. Its purpose is to determine which mining events and values are genuinely present in game-generated output before MFA attempts to replace OCR.

## Safety boundary

The probe deliberately does **not**:

- read Star Citizen process memory;
- inject DLLs or code;
- intercept or decode network traffic;
- modify game files;
- send control input to the game;
- automate gameplay.

It only opens `Game.log` as a shared-read text file.

RSI documents the default LIVE log path as:

```text
<install drive>:\Program Files\Roberts Space Industries\StarCitizen\LIVE\Game.log
```

Custom install locations are supported by passing `--path`.

## Run from source

Requires .NET 8 SDK:

```powershell
cd tools\MfaTelemetryProbe
.\run-probe.ps1
```

Custom game location:

```powershell
.\run-probe.ps1 -GameLog "D:\Games\Roberts Space Industries\StarCitizen\LIVE\Game.log"
```

To capture the already-existing current log as well as future lines:

```powershell
.\run-probe.ps1 -FromStart
```

For a smaller capture containing only candidate lines:

```powershell
.\run-probe.ps1 -CandidatesOnly
```

## Output

By default:

```text
%LOCALAPPDATA%\MFA\TelemetryProbe\<timestamp>\
    session.json
    events.jsonl
    candidates.jsonl
```

- `session.json` describes the probe run.
- `events.jsonl` contains every line appended during the run.
- `candidates.jsonl` contains lines that matched broad research keywords.

Candidate categories are intentionally broad. A match such as `laser`, `scan`, or `cargo` is **not** treated as proof of a mining mechanic. We will derive semantics only from repeatable controlled observations.

## Controlled mining capture protocol

Start the probe immediately before the test session, then perform one action at a time:

1. launch Star Citizen LIVE;
2. enter a mining ship;
3. power the mining system;
4. enter mining mode;
5. acquire a rock target;
6. scan the rock;
7. keep the target stable for several seconds;
8. switch mining laser/head if possible;
9. toggle a mining module;
10. apply/remove a gadget if applicable;
11. begin fracture;
12. enter/leave the optimal charge zone;
13. complete or abort fracture;
14. extract material;
15. observe cargo/inventory changes;
16. stop the probe with Ctrl+C.

Record the real on-screen value/action and approximate time for each step. That gives us a ground-truth timeline to compare with the captured log.

## Privacy

Raw game logs can contain system, account, session, server or diagnostic information.

Do **not** post `events.jsonl` or the original `Game.log` publicly.

For MFA development, start by sharing only the relevant candidate excerpts after reviewing them. A future probe revision can add structured redaction once we know which fields are required for reliable telemetry.

## Decision gate

OCR will only be replaced for a field when the probe demonstrates a stable, repeatable game-generated source for that field on the current Star Citizen build.

Until then:

```text
verified live telemetry > OCR > manual input
```
